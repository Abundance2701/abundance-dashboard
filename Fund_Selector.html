Does the score pick better funds? tested only on data that was available at the time

On each test date (October of each year from 2014 to 2023), every fund is scored using only its history up to that date. Then the tool checks how each fund actually did against its index over the next 3 years. If the score works, high-scored funds should have done better than low-scored ones. The same test is run on each part of the score, and on simply picking the best past 3-year return (what most investors do), for comparison.

Category → yardstick

What this table is: what each category is measured against. For equity categories it is the category's official Tier-1 index, as a Total Return Index (price plus dividends reinvested), the fair comparison because NAVs include dividends. Debt, hybrid and other categories have no free official index data, so they are compared with the median of their own peers (the middle fund's return each month).

Index returns (TRI)

What this table is: returns of every index the tool stores: broad market and size indices, style indices (value, quality, momentum, low volatility) and sector indices. It shows which part of the market led over each period. The style indices also power the "Style & bets" analysis.
