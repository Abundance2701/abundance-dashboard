Category → official benchmark (Tier 1)

What this table is: the yardstick each category is measured against. SEBI makes every fund declare a "Tier-1" benchmark, which is common to its whole category (e.g. all large cap funds use the Nifty 100). The tool uses the Total Return version of that index (TRI: price plus dividends reinvested), which is the fair comparison because fund NAVs also include dividends. The last column links the official document confirming each mapping.

Index returns (TRI)

What this table is: the returns of every index the tool stores: the broad market and size indices (benchmarks), style indices (value, quality, momentum, low volatility, equal weight) and sector indices. It shows which part of the market led over each period, e.g. whether value or momentum did better over 3 years. Phase 2 uses the style indices to work out each fund's real style mix, so a portfolio can be kept from leaning on one style.
